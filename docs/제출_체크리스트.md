## 남은 일 — 사람만 할 수 있는 것

### ☐ 1. 기술설명서 표지의 팀 정보 3칸

표지(1쪽)의 **팀명 · 팀원 · 소속**을 점선 공란으로 비워 뒀다. PPTX 슬라이드는 이미지라
파워포인트에서 글자를 고칠 수 없다 — **원본 HTML을 고치고 다시 빌드**한다.

`docs/deck/온전_기술설명서.html`에서 이 부분을 찾는다.

```html
<dt>팀명</dt><dd><span class="blankfill">&nbsp;</span></dd>
<dt>팀원</dt><dd><span class="blankfill">&nbsp;</span> <span class="blankfill">&nbsp;</span></dd>
<dt>소속</dt><dd><span class="blankfill">&nbsp;</span></dd>
```

`<span class="blankfill">&nbsp;</span>`를 실제 값으로 바꾼다. 값은 참가신청서 2번 표
(`01_참가신청서/…참가신청서.docx`)에 이미 적어 둔 것을 그대로 옮긴다 — 두 문서가 다르면
심사자가 어느 쪽을 믿어야 할지 알 수 없다.

```html
<dt>팀명</dt><dd>○○○</dd>
<dt>팀원</dt><dd>○○○(팀장) · ○○○</dd>
<dt>소속</dt><dd>○○대학교 ○○학과 · ○○대학교 ○○학과</dd>
```

> 이 저장소는 공개돼 있다. **실명·학교·연락처를 저장소 안 파일에 적지 않는다.**
> 개인정보는 참가신청서 docx(제출 zip 안, 저장소 밖)에만 둔다.

고친 뒤 다시 빌드한다. PPTX와 PDF가 **같은 PNG**를 쓰므로 둘이 어긋날 수 없다.

```bash
.venv/bin/python scripts/build_deck.py     # 24장 재렌더 → dist-docs/*.pptx, *.pdf
./scripts/make_submission.sh               # zip 재생성
```

### ☐ 2. 참가신청서 docx 마무리

`01_참가신청서/제8회_Future_Finance_AI_Challenge_참가신청서.docx`에 이미 팀명·과제명·
과제요약·팀원 정보가 들어 있다. 남은 것은 **손으로 체크·서명해야 하는 칸**이다.

- ☐ 2번 표 — 팀장·팀원의 **재학 구분** (재학 / 휴학) 체크
- ☐ 3번 표 — AI 활용 **결과물 반영 정도** (참고 / 일부반영 / 대부분활용) 체크
- ☐ 하단 **날짜**를 제출일로 (현재 `2026년 7월 31일`)
- ☐ 하단 **신청인(팀장) 서명 또는 날인**
- ☐ PDF로 내보내 docx와 함께 넣기 (서명이 들어간 형식이 안전하다)

### ☐ 3. 서약서 — **팀원 각각** 작성·서명

`01_참가신청서/서식_원본(서명전)/제8회 Future Finance AI Challenge 서약서.pdf`

- ☐ 팀장 서명본
- ☐ 팀원 서명본
- ☐ 서명본을 `01_참가신청서/`에 넣고 `서식_원본(서명전)/` 폴더는 zip에서 지운다

### ☐ 4. 개인정보 수집·이용 동의서 — **팀원 각각**

`01_참가신청서/서식_원본(서명전)/[필수]개인정보 수집·이용 동의서(...).pdf`

- ☐ 팀장 서명본
- ☐ 팀원 서명본

> 참가신청서 첨부1이 "참가 서약서 및 개인정보 수집·이용 동의서 1부 **(개인별 작성 필요)**"라고
> 명시한다. 2인 팀이면 각 서식이 2부씩, 총 4장이다.

### ☐ 5. zip 재생성 후 업로드

```bash
./scripts/make_submission.sh
```

- ☐ zip을 풀어 `01_참가신청서/`에 **서명본 4장**이 들어 있는지 눈으로 확인
- ☐ `서식_원본(서명전)/` 폴더가 남아 있지 않은지 확인
- ☐ 사이트 업로드 → 진행률 **100%** 확인 후 「등록하기」 클릭 (100% 전에 누르면 거부된다)
